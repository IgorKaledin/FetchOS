# Fetch OS 🚀

> **Fetch OS** — современный, быстрый и кастомизируемый дистрибутив Linux на базе передовых технологий экосистемы Arch Linux.

---

## 📁 Структура проекта

```
Fetch OS/
├── upstream/                     # Оригинальные исходные коды базовых компонентов
│   ├── archiso/                 # Движок сборки загрузочных ISO-образов
│   ├── arch-install-scripts/    # Скрипты установки системы (pacstrap, genfstab, arch-chroot)
│   └── calamares/               # Модульный графический инсталлятор системы
│
├── fetch-os-profile/             # Профиль конфигурации и сборки Fetch OS
│   ├── profiledef.sh            # Метаданные ОС (название, версия, параметры ISO)
│   ├── packages.x86_64          # Список пакетов, устанавливаемых в систему и Live-образ
│   ├── pacman.conf              # Конфигурация репозиториев (Fetch OS repos, Arch, Chaotic)
│   ├── airootfs/                # Корневая файловая система (overlay: конфиги, темы, скрипты)
│   │   ├── etc/
│   │   │   ├── os-release       # Идентификация Fetch OS
│   │   │   └── issue            # Консольное приветствие
│   │   └── root/                # Начальные настройки пользователя
│   ├── efiboot/                 # Файлы UEFI загрузчика
│   └── syslinux/                # Файлы BIOS загрузчика
│
├── tools/                        # Собственные утилиты и CLI-инструменты Fetch OS
│   ├── fetch-cli/               # Фирменная системная утилита Fetch OS
│   └── scripts/                 # Вспомогательные скрипты сборки и тестирования
│
└── build-iso.sh                  # Главный скрипт автоматической сборки ISO
```

---

## 🛠️ Как собирается образ

Сборка осуществляется с помощью движка `mkarchiso`:
1. Подготавливается изолированное окружение chroot.
2. Устанавливаются базовые пакеты, ядро и драйверы из `packages.x86_64`.
3. Накладывается слой `airootfs` (фирменные настройки, темы, брендинг).
4. Создается сжатый образ `squashfs`.
5. Генерируется гибридный загрузочный образ `fetch-os-x86_64.iso` (поддерживает UEFI и Legacy BIOS).

## 🚀 Быстрый старт сборки (в Linux / WSL2 / Docker)

```bash
# Запуск сборки
sudo ./build-iso.sh
```
